# Project Rules

This is a learning-first beginner project.

## Stack

- Python
- Flask
- Python built-in sqlite3
- SQLite
- Jinja HTML templates
- Basic CSS

Do not introduce React, SQLAlchemy, Docker, cloud services,
authentication, or AI APIs during the MVP.

## Working rules

1. Read existing files before editing.
2. Work on only one small feature at a time.
3. Before editing, explain:
   - the goal
   - the data flow
   - which files will change
4. Prefer the smallest working modification.
5. Do not rewrite unrelated code.
6. Do not add dependencies without explaining them.
7. Run the relevant checks after modifying files.
8. Summarize the diff afterward.
9. Never commit or push unless explicitly requested.
10. For core logic, give the user a chance to attempt it first.
11. Explain errors before fixing them.
12. Update PROJECT_STATUS.md after completing a milestone.

## Communication Language

- Use English as the default communication language.
- Keep code, filenames, variable names, comments, documentation,
  commit messages, and technical terminology in English.
- The user may ask questions in Chinese when English becomes an obstacle.
- When the user writes in Chinese, answer in Chinese unless they request English.
- When explaining in Chinese, preserve important technical terms in English
  alongside the Chinese explanation.
- Prefer clear and simple English over unnecessarily advanced vocabulary.
- Language difficulty must not prevent the user from asking questions
  or understanding the code.
