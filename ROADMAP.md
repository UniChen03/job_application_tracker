# ROADMAP

## Current State

The core MVP is complete and development is currently paused.

## Possible Future Improvements

- Display friendly success and validation messages inside the application.
- Preserve submitted form values when validation fails.
- Record status changes in a separate history table.
- Add pagination if the number of applications becomes large.
- Add deployment configuration for hosting the application.
- Expand automated tests for browser-side interactions.

## Outside the Current MVP

- User authentication
- Multiple user accounts
- Cloud database services
- AI features
- Third-party job board integrations

These features are not currently planned and would only be considered if the project scope expands.
